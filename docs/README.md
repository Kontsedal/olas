# The docs site

A [VitePress](https://vitepress.dev) site, built from this folder and from the repo's own docs. The site does not render this file.

```bash
pnpm docs:build     # build the packages, check the API reports, sync, build the site
pnpm docs:dev       # sync, then serve with hot reload (needs a prior `pnpm build && pnpm api:check`)
pnpm docs:preview   # serve the built site
```

## What is written here, and what is generated

Written here, and checked by `pnpm check:doc-snippets` like the other docs:
- `index.md`, the home page;
- the guide pages in `guide/` that have no "Generated from" comment: getting-started, concepts, queries, mutations, forms, ssr, testing and performance.

Generated by `scripts/docs-sync.mjs`, and gitignored:
- `guide/recipes.md`, `guide/plugins.md` and `guide/migration.md`, from `RECIPES.md`, `PLUGINS.md` and `MIGRATING.md`.
- `adapters/` and `packages/`, from the package READMEs.
- `reference/`, the API reference. `api-documenter` builds it from the doc model that `pnpm api:check` writes to `temp/api-model/`.

Edit a generated page at its source. The sync rewrites the source's relative links. A link to another synced doc becomes that page's route, and any other link points at the file on GitHub.

## Deploying

`.github/workflows/docs.yml` builds the site on every pull request. It deploys to GitHub Pages only when someone runs it by hand with `deploy` ticked. Pages must be enabled first, in the repository settings under Pages, with GitHub Actions as the source. The site is served under `/olas/`, which is `base` in `.vitepress/config.mts`.
